## Sections (top to bottom)

1. **Toolbar** — window title, search/filter field, settings icon
2. **Downloads list** (main area) — one row per torrent: name, progress bar, download speed (↓), upload speed (↑), seeders/leechers
3. **Empty state** — shown when no active downloads

**Deliberately excluded:** footer/status bar — aggregate stats already live in the menu bar (Scenario 04), avoiding duplication.
