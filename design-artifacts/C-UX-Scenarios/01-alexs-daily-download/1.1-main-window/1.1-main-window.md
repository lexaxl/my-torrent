## Overview

**Page Purpose:** Show all active downloads at a glance and let a newly opened torrent start downloading immediately with zero setup friction.

**User Situation:** At his Mac, just found something he wants to download (e.g. a Linux ISO or software distribution) via Safari or a saved `.torrent` file. On internal-navigation entries (menu-bar, detail view), the situation is calmer — a routine status check.

**Success Criteria:** A newly opened torrent appears in the list and starts downloading within a second, with no dialog interrupting the flow; Alex can locate any torrent to inspect within one glance/scroll.

**Entry Points:**
- Double-click a `.torrent` file in Finder, or click a magnet link in the browser (first open — app opens/comes to foreground)
- Click the menu-bar icon → "Открыть окно" (returning from a quick glance, Scenario 04)
- Close the torrent detail view (returning from Scenario 02)
- Launch from Dock if the app was already open

**Exit Points:**
- Clicks a torrent row → Torrent Detail (2.2)
- Clicks settings icon → Settings (3.1)
- No exit required — may simply stay open in the background

## Layout Structure

Toolbar directly above the downloads list (no gap — one continuous unit, like Finder/Mail), list fills the remaining window height, empty state replaces the list entirely when there are no downloads.

```
+----------------------------------------------------+
| my-torrent          [search field]     [settings]  |  ← Toolbar
+----------------------------------------------------+
| Имя      Прогресс      ↓      ↑      Сиды/Личи     |  ← Column headers
+----------------------------------------------------+
| torrent-row (repeats, one per active download)     |
| ...                                                 |
+----------------------------------------------------+
```

Empty state (replaces column headers + rows when list is empty):
```
+----------------------------------------------------+
| my-torrent          [search field]     [settings]  |
+----------------------------------------------------+
|              Нет активных закачек                  |
+----------------------------------------------------+
```

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Default (populated) | ≥1 active/seeding torrent | Toolbar + column headers + list of rows | Search, click row, click settings |
| Empty | 0 torrents | Toolbar + centered empty-state message, no headers/rows | Search (no-op), click settings |
| Row: downloading | Torrent actively transferring | Live progress bar, ↓/↑ speed, seed/leech count updating continuously | Click → detail view |
| Row: complete/seeding | Progress reaches 100% | Progress shows 100%/"seeding" per global seed-duration default; ↑ speed may continue, ↓ shows 0 | Click → detail view |
| Row: tracker error (torrent-level, not page-level) | A specific torrent's tracker unreachable | Small warning indicator on that row only — rest of list unaffected | Click → detail view shows tracker status |

_No page-level Loading or generic Error state — this is a local app with no server data fetch; per-torrent issues surface at the row level only, not as a whole-page state._

## Technical Notes

- Row data (progress, speeds, peer counts) updates live from the Rust protocol engine — exact update frequency/IPC mechanism to be defined at Architecture.
- Row click target should be generous (entire row, not just the name) — supports the "zero friction" philosophy.
- Toolbar/list are native platform components (e.g. `NSToolbar` + `NSTableView`/SwiftUI `List`, depending on final UI framework choice at Architecture) — exact widget choice deferred.
