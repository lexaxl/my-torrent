## Overview

**Page Purpose:** Let Alex configure global default behavior — save location and seeding duration — once, so it never needs revisiting per torrent.

**User Situation:** Shortly after installing the app, before relying on it daily.

**Success Criteria:** Alex sets both defaults in one pass and never needs to reopen this screen unless something changes.

**Entry Points:**
- Menu item from [Главное окно](../../01-alexs-daily-download/1.1-main-window/1.1-main-window.md) toolbar (settings icon)
- Menu item from [Меню-бар](../../04-alex-glances-at-the-menu-bar/4.1-menu-bar/4.1-menu-bar.md) popover

**Exit Points:**
- Closes Settings → returns to whichever screen it was opened from

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Default | Screen opened | Both fields show current values (defaults on first open, or previously saved values) | Change save location, change seed duration, close |
| Value changed | Any control interacted with | New value takes effect immediately — no confirmation/save step, no dirty-state indicator needed | Continue adjusting, close |

_No page-level Loading/Error/Empty states — this is a simple local preferences screen with no network dependency._

## Technical Notes

- Instant-apply means preferences persist immediately on change (e.g. to `UserDefaults` or equivalent local config store) — no explicit save/cancel flow, confirmed by user during specification.
- Additional global defaults may be added to this screen later (per `D-Design-System` note in the earlier conceptual pass) — this spec covers only the two confirmed hard requirements.
