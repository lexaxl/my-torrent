## Sections (top to bottom)

1. **Заголовок** — «Настройки», закрыть
2. **Папка для сохранения по умолчанию** — путь + выбор через файловый диалог
3. **Период раздачи по умолчанию** — режим выбора: не раздавать / N часов / бессрочно

Намеренно минимально — только два подтверждённых требования (папка, период раздачи). Остальные глобальные настройки добавятся по мере необходимости на Architecture/дальнейших итерациях.
