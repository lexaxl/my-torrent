## Overview

**Page Purpose:** Provide an at-a-glance summary of activity (aggregate download/upload speed, active count) without requiring the main window to be open.

**User Situation:** Busy with another task on his Mac; downloads are running in the background; wants a quick ambient check without breaking focus.

**Success Criteria:** Alex sees aggregate speed/count within one click, without the main window ever needing to open.

**Entry Points:**
- Menu-bar icon is always present while the app is running

**Exit Points:**
- Dismisses popover (clicks elsewhere) — no further action
- "Открыть окно" → [Главное окно](../../01-alexs-daily-download/1.1-main-window/1.1-main-window.md)
- "Настройки" → [3.1 Настройки](../../03-alex-sets-defaults-once/3.1-settings/3.1-settings.md)

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Icon: idle | No active transfers | Baseline icon (exact visual TBD at visual design) | Click → popover (shows empty state) |
| Icon: active | ≥1 active transfer | Icon reflects activity (exact visual treatment TBD) | Click → popover (shows stats) |
| Popover: populated | ≥1 active download at click time | Stats block + actions block | Dismiss, open window, open settings |
| Popover: empty | 0 active downloads at click time | Empty-state message + actions block (actions still available) | Dismiss, open window, open settings |

## Technical Notes

- Click-to-open-popover was deliberately chosen over hover-tooltip during the conceptual pass — more reliable/discoverable for macOS status bar items.
- Aggregate speed = sum of all active torrents' current speeds; recomputed on the same update cadence as Главное окно's row-level speeds (exact cadence TBD at Architecture).
