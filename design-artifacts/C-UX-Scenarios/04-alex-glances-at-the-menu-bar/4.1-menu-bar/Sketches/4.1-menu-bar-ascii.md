**Method:** ASCII layout (rough structural guide, not final visual design)
**Created:** 2026-07-27

---

## Icon at rest (idle / no active transfers)

```
 ⋯ 🕸  🔊  📶  [⇅]  Пт 14:32
              ↑
         my-torrent icon (idle state)
```

## Icon active (click → popover)

```
 ⋯ 🕸  🔊  📶  [⇅↓]  Пт 14:32
              ↑ click
              │
              ▼
        ┌───────────────────────┐
        │  ↓ 5.3 MB/s            │
        │  ↑ 0.4 MB/s            │
        │  2 активные закачки    │
        ├───────────────────────┤
        │  Открыть окно          │
        │  Настройки             │
        └───────────────────────┘
```

---

## Sections

1. **Icon (always present)** — reflects idle vs. active state (exact visual treatment — e.g. arrow direction, subtle animation — TBD at visual design, Apple HIG-consistent)
2. **Popover (on click)** — aggregate download/upload speed, active download count, quick actions (open main window, settings)

**Interaction decision:** Click-to-open popover, not hover-tooltip — more reliable/discoverable on macOS status bar items than hover (hover tooltips are inconsistent and less standard for status items). The icon itself may still convey coarse state at a glance (idle vs. active) without needing a click.

⚠️ Rough structural guide only — lacks visual hierarchy, spacing, typography, color, exact icon design.
