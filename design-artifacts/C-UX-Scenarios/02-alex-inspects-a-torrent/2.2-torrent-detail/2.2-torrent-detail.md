## Overview

**Page Purpose:** Show everything about one specific torrent — files inside, tracker status, connected peers — the "depth on demand" layer of the Product Concept.

**User Situation:** Mid-download, wants to check a specific torrent's status without disrupting the overall simple view.

**Success Criteria:** Alex understands the torrent's status (files, trackers, peers) within seconds and can close the view without needing to search for the info elsewhere.

**Entry Points:**
- Clicks a torrent row on [2.1 Главное окно](../2.1-main-window/2.1-main-window.md)

**Exit Points:**
- Closes/dismisses the view → returns to [Главное окно](../../01-alexs-daily-download/1.1-main-window/1.1-main-window.md)

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Default (Files tab, selected on open) | Torrent has ≥1 file (always true) | List of files with size/progress | Switch tabs, close |
| Default (Trackers tab) | Torrent has ≥1 tracker (always true) | List of trackers with status | Switch tabs, close |
| Default (Peers tab, populated) | ≥1 peer connected | List of peers with speed/role | Switch tabs, close |
| Empty (Peers tab) | 0 peers connected | Centered "Нет подключённых пиров" message | Switch tabs, close |

_No page-level Loading/Error state — data is local/live from the protocol engine; per-tracker connection issues surface as a status value within the Trackers row, not a page-level error._
